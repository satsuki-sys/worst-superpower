A [make.fun](https://make.fun/c/u-suroto-worst-superpower-461dcdbe) entry for the
**Worst Superpower** competition: invent the most useless superpower in one line
of at most 140 characters.

## Entry

> I can make any object float, but only objects I'm already holding, and only while I keep holding them.

## Run

```sh
node main.ts
```

`main.ts` writes the one-line entry to `/output/entry.txt` (102 characters).
